## Tag rule / 打 tag 规则

1. Checklist P1–P7 evidence exists (P6 PASS drill on disk). **P1 remote image-scan must be re-checked** after push.
2. Re-read SECURITY.md zh/en for drift (Cedar default, O8, Scale-4d).
3. Do **not** claim production-ready. After a green remote CI and intentional cut, wording may say **evaluation build per this checklist**.
4. No force-push; no tag until you accept remaining reds (remote CI / optional compose smoke).
