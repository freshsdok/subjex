# Codegen page / 生成类型页
Evidence opened before designing `GET /codegen`. These are the pages that were read, not a copied generator.
- jOOQ can add a JDK generated annotation to every generated class, carrying the jOOQ version, the schema version, and the generation date. https://www.jooq.org/doc/latest/manual/code-generation/codegen-advanced/codegen-config-generate/codegen-generate-annotations/
- A schema version provider writes that version into `javax.annotation.Generated` on the generated artefacts, so the type documents which schema version it came from. https://www.jooq.org/doc/latest/manual/code-generation/codegen-advanced/codegen-config-database/codegen-database-version-providers/
- The same generator copies `COMMENT` text from schema objects into Javadoc, so the words attached to the source table or column travel with the generated type. https://www.jooq.org/doc/latest/manual/code-generation/codegen-advanced/codegen-config-database/codegen-database-comments/
- The miss this page is built against: looking back at generated sources, people cannot trace the file to the definition that produced it. An OpenAPI class annotation names a generator and a date, not a version they can match, and a generated file can be named for one schema while holding another schema's fields. https://github.com/OpenAPITools/openapi-generator/issues/17681 https://github.com/OpenAPITools/openapi-generator/issues/22012
`GET /codegen` is the opposite of that complaint. One sentence says this page shows the type generated from the form, not a generator you run from the browser. Then the record name, and each component with its type, Chinese first and English second. Those values are read from the checked-in `EndpointPublication` record and checked against `endpoint-publication.form.yaml` through `FormRenderer` and `FormRecordGenerator`. There is no button that writes a file.
`GET /codegen` 对着的就是这个抱怨。一句话说明这一页展示从表单生成的类型，不是在浏览器里运行的生成器。然后是记录名，以及每个组件和它的类型，中文在前、英文在后。这些值读自已检入的 `EndpointPublication`，并经 `FormRenderer` 与 `FormRecordGenerator` 与 `endpoint-publication.form.yaml` 核对。没有写文件的按钮。
